## 문제

운영 정책과 API 스펙이 세 곳에 흩어져 있어, 답을 아는 사람에게 묻는 편이 빨랐습니다.
문서는 있는데 찾지 못하는 상태였습니다.

## 만든 것

1. 문서 수집기 — 위키·저장소·스프레드시트를 하루 한 번 동기화
2. 청크 분할과 임베딩 — 문단 경계를 지키도록 분할 규칙을 조정
3. 답변 생성 — 인용한 문서 링크를 항상 함께 노출

## 배운 것

검색 품질이 답변 품질을 거의 결정했습니다. 모델을 바꾸는 것보다 청크 규칙과
메타데이터 필터를 손보는 쪽이 체감 개선이 컸습니다.
